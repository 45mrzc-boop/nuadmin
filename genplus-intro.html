Getting Started Guide

极速上手 4 步走：从 0 到 独立子系统

开箱即用，只需几条标准命令，即可在本地完整跑通全流程。

1
准备环境与导入控制面数据库

确保本机已安装 Node.js >= 18 与 MySQL 8.0+。执行根目录下的 nuadmin.sql 即可一键初始化控制面库与预设字典：

mysql -h 127.0.0.1 -P 3306 -u root -p < nuadmin.sql
2
配置并启动主控制面服务 (Port 6005)

进入 main-admin 目录，复制环境配置模板并启动：

cd main-admin && cp .env.example .env && npm install && npm run dev

启动后访问 http://localhost:6005，默认管理员账号：admin / 密码：admin123

3
通过 AI 对话或 9 大工位一键立项建模

使用 AI 智能体对话（输入如：“构建一套医院预约挂号系统并装配数据看板和官网CMS”），选择【简略模式】单轮确认，或在工位中精细勾选 18 项能力包与门禁鉴权形态。

4
一键生成独立工程与脱耦独立部署

在【生成站】点击生成，工程将自动输出至 tenants/<slug>，可脱离控制面独立部署：

cd tenants/app_demo && npm install && npm run build

产出标准的 .output/server/index.mjs，支持 Docker 容器化或 PM2 部署上线。
