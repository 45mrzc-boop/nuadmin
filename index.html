企业级开源 SaaS 系统的 4 大核心架构优势

不写死运行时、不绑死平台组件，把生产级多租户 SaaS 研发的最佳实践固化在生成引擎中。

01

Skills + MCP 双模式驱动（脑手合一）

坚持“Skills 定规程，MCP 通底层”。杜绝一句话盲目生成。提供 genplus-build 简略/细节双轨立项与 genplus-maintain 增量维护。大模型通过标准化 MCP 协议直通 7 大控制面、独立数据库与无头浏览器真机截图。

genplus-mcp.mjs CDP 无头渲染 双轨对齐
02

完全自治与 100% 物理隔离的多租户架构

每个子系统生成在独立目录中，拥有自己的独立 MySQL 数据库（nuadmin_t_*）、专属 JWT 秘钥与独立端口。即使把主控制面整库删除，生成的子后台依旧可以直接 npm run build 并在生产环境独立运行。

零平台绑定 独立 JWT 独立端口
03

B + C 双端闭环与纯静态微门户

不止能构建中后台系统！通过一键装配 landing_cms、landing_poster、landing_form 等微门户能力，平台能同步生成**纯静态、0-API 水合、自带暗黑主题的对外公开门户**，实现全链路业务闭环。

纯静态 CMS 渠道海报二码 表单动态收集
04

毫秒级工业编译，Token 消耗直降 95%

传统 AI 编程需大模型持续吐出成千上万行 Vue 模板与 Nitro 路由，极易断流报错；GenPlus 让模型只需决策几十 Token 的结构化描述，由本地确切编译引擎（Deterministic Industrial Engine）毫秒级完成全套 SaaS 工程编译。

Getting Started Guide

极速上手 4 步走：从 0 到 独立 SaaS 子系统

开箱即用，只需几条标准命令，即可在本地完整跑通全流程。

1
准备环境与导入控制面数据库

确保本机已安装 Node.js >= 18 与 MySQL 8.0+。执行根目录下的 nuadmin.sql 即可一键初始化控制面库与预设字典：

mysql -h 127.0.0.1 -P 3306 -u root -p < nuadmin.sql
2
配置并启动主控制面服务 (Port 6005)

进入 main-admin 目录，复制环境配置模板并启动：

cd main-admin && cp .env.example .env && npm install && npm run dev

启动后访问 http://localhost:6005，默认管理员账号：admin / 密码：admin123

3
通过 AI 对话或 9 大工位一键立项建模

使用 AI 智能体对话（输入如：“构建一套医院预约挂号系统并装配数据看板和官网CMS”），选择【简略模式】单轮确认，或在工位中精细勾选 18 项能力包与门禁鉴权形态。

4
一键生成独立工程与脱耦独立部署

在【生成站】点击生成，工程将自动输出至 tenants/<slug>，可脱离控制面独立部署：

cd tenants/app_demo && npm install && npm run build

产出标准的 .output/server/index.mjs，支持 Docker 容器化或 PM2 独立上线部署。
